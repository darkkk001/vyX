# Endpoints audit (2026-09-24, read-only)

Scope: every `app/api/**/route.ts` in D:\VyXTrader-Tauri\vyX (web = D: main HEAD), every URL string in E:\vyxtrader\src\Vyx.Shared\Api\ApiClient*.cs (+ ClientManifest.cs and the 3 WebSocket clients), the API gateway (services/api-gateway) and the Rust engine HTTP router (engine/server/src/main.rs).

How this was built (so the reader can judge confidence):
- Backbone: a script listed all 184 `route.ts` files and split each into its exported handlers. Result: **227 method+path rows** (manage 117, trade 52, admin 31, portal 18, internal 7, client 1, public 1).
- Auth column: guard calls read per handler, including local helpers such as `requireManager()` (cited file:line = first guard line). Role semantics: `requireAdminRole` = exact role list (lib/auth.ts:317); `forbidUnlessBrokerAdminOrPermission` = BROKER_ADMIN, or MANAGER with that delegated permission and ACTIVE status (lib/permissions.ts:26-30); `getPermissionContext().forbidUnless` = same rule (lib/permissions.ts:66-101). SUPPORT and SUPER_ADMIN do not pass either.
- Every admin guard runs through `getAdminSession()` (lib/auth.ts:224-300). It checks the Redis session, the native client-build binding, the x-broker-id tenant, and the live admin status/role. It revokes sessions of a disabled admin and forces 2FA enrollment for SUPER_ADMIN.
- Writes column: Prisma write calls in the handler, plus "via lib" = static call-graph closure over lib/*.ts. The closure follows every branch, so "via lib" lists every table a handler **can** write, not what one request always writes. Redis writes were added by hand where known.
- Side effects: AuditLog rows, NATS trading events (lib/nats.ts:104 publishes through the gateway `POST /internal/events`, lib/nats.ts:121), `account.updated` events (lib/account-events.ts), admin Notification rows (lib/notifications.ts:10), dealer-activity (lib/dealer-activity.ts:73 = NATS DealerActivity event + optional Notification), mirror (lib/mirror.ts onFill/onClose), coverage (lib/coverage.ts onClose / onFillAutoHedge / ensureCoverageAccount), commission (lib/group-pricing.ts chargeCommission), email (lib/email/adapter.ts:118).
- Used by: native callers are ApiClient method -> call sites in E:\vyxtrader\src. BO: = Vyx.Backoffice.App, TERM: = Vyx.Trader.App, SH: = Vyx.Shared. Harness-only call sites (Program.cs) are excluded. WEB: = Next.js pages/components/lib callers. TAURI = retired Tauri shells (manager-tauri/desktop-tauri/admin-tauri). INFRA = engine, EA, cron, middleware, scripts. Same-name ApiClient overloads (FetchAuditAsync, CloseBulkAsync, ReversePositionAsync) were split by hand.
- middleware.ts does broker resolution only. It adds no API auth: `/manage/*` gate commented out (middleware.ts:127-143), `/api/internal/*` excluded from the matcher (middleware.ts:354).
